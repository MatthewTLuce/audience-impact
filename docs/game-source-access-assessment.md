# Narrative-game source assessment

Checked September 25, 2026. Read-only documentation review; no review endpoint was called and no reviews were acquired.

Steam publishes a review-list endpoint returning structured JSON, with language, recommendation, purchase-type and pagination controls. The documentation notes a default off-topic-activity filter and a maximum of 100 reviews per request. These filters can affect the sample and must be recorded. This establishes a practical technical route, not permission for this study's intended processing or retention.

Source: https://partner.steamgames.com/doc/store/getreviews

The published Steam Web API terms contain conditions about end-user data requests, stored data/privacy notices, permitted distribution and unsolicited marketing. Their applicability to the store review endpoint and the planned research/commercial-hypothesis use has not been resolved here. No API key, agreement acceptance or claim of commercial reuse rights is made. Keep Steam acquisition disabled until the operator has a documented permitted method and retention/use scope.
